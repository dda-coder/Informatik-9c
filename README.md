# Memorie

Das ist ein Memorie-Spiel, das ich im Informatikunterricht in der 9. Klasse erstellt und danach weiter bearbeitet habe. Man kann damit Karten aufdecken und passende Bildpaare suchen.

## Spielvarianten

- Einzelspieler-Version
- Zwei-Spieler-Version mit Punkten und wechselnden Spielzügen

## Technik

Das Spiel ist mit HTML, CSS und JavaScript programmiert. Die Karten und das Spielfeld werden im Browser angezeigt. Für die Karten werden verschiedene eigene bzw. eingebundene Bilder verwendet.

## Starten

Die HTML-Dateien können direkt im Browser geöffnet werden. Für die Zwei-Spieler-Version gibt es die Datei `memorie 2P.html`.

Das Projekt war eine meiner ersten größeren praktischen Arbeiten mit HTML und JavaScript.
